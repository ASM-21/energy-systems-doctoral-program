# Repository Guide

## Source of truth
The repository is the canonical program record. Course materials, research notes, code, data provenance, and progress evidence belong here. Chat discussions and generated drafts are not authoritative until reviewed and committed.

## Naming
Course IDs use Y<year>-<sequence>, e.g. Y1-01. Project folders use short lowercase kebab-case names. Research papers use YYYY-short-title.

## Changes
For material curriculum changes, explain rationale; identify affected prerequisites; update roadmap/catalog; update trackers; preserve completed work and historical evidence.

## Branch workflow
Use feature branches for substantial curriculum or software changes. Keep main stable. Review generated content for accuracy, citations, licensing, and consistency.

## Website
The published [GitHub Pages site](https://asm-21.github.io/energy-systems-doctoral-program/) is generated from repository content. The site is a navigable view, not a second source of truth. Avoid duplicating course text in manually maintained HTML.
