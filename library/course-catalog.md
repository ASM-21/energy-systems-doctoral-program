## Notes on source verification

- Purdue's ECE graduate catalog warns that terms offered can vary with instructor availability.
- Purdue ECE 51020's detailed page lists prerequisites and a course outline; the listed requisites are substantial. The independent curriculum should diagnose gaps rather than assume automatic equivalence.
- CMU's page identifies the course as 39-612 and cross-lists it as 45-916 and 19-666. Use the exact identifier relevant to the catalog being consulted.
- Stanford ECON 253's catalog description explicitly welcomes PhD students but the accessed page did not show an available section. No inference about next offering should be made.
- No entry should be labeled "public syllabus" unless a syllabus document itself has been located and checked.
