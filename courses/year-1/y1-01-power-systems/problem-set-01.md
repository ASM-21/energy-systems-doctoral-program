# Y1-01 Problem Set 1 — Three-Phase Fundamentals and Per-Unit Quantities

**Instructions:** Show equations, units, assumptions, and intermediate steps. Use RMS quantities. Assume balanced positive-sequence operation unless stated otherwise.

## Problem 1 — Three-phase load

A balanced three-phase load connected to a 13.8 kV line-to-line system consumes 10 MW at 0.90 lagging power factor.

1. Calculate apparent power.
2. Calculate reactive power.
3. Calculate line current.
4. Explain what changes if power factor improves to 0.98 while real power and voltage remain constant.
5. Explain why this calculation alone does not establish that the feeder can serve the load.

## Problem 2 — Per-unit impedance

A three-phase system uses a 100 MVA base and 13.8 kV line-to-line voltage base. A per-phase series impedance is 0.5 + j1.5 ohms.

1. Calculate the impedance base.
2. Convert the impedance to per unit.
3. State the corresponding current base.
4. Explain why per-unit quantities simplify transformer-connected network calculations.

## Problem 3 — Approximate feeder voltage drop and losses

A balanced 13.8 kV feeder supplies the load in Problem 1 through a series impedance of 0.2 + j0.4 ohms per phase. Use the receiving-end current from Problem 1 and the approximate voltage-drop expression:

    delta_V_LL ~= sqrt(3) * I * (R cos(phi) + X sin(phi))

1. Estimate line-to-line voltage drop and percentage drop.
2. Estimate three-phase real power loss using 3 I^2 R.
3. State the assumptions behind these approximations.
4. Explain why voltage drop and thermal loading are separate constraints.

## Problem 4 — Engineering interpretation

A developer proposes adding 4 MW of inverter-based PV to the feeder. List the minimum additional information needed before concluding whether the PV can be interconnected without upgrades. Organize the information into network, load, protection/control, and operating-data categories.

## Submission standard

A complete solution includes derivations, dimensional checks, numerical answers, and a short interpretation. A numerical answer without reasoning is incomplete.
